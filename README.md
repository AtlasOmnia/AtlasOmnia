## Free tools

| Tool | What it does |
| --- | --- |
| [**hermes-custom-pack**](https://github.com/AtlasOmnia/hermes-custom-pack) | Installable Hermes skills. Browse the [skill catalog](https://github.com/AtlasOmnia/hermes-custom-pack#skills). |
| [**hermes-tool-router**](https://github.com/AtlasOmnia/hermes-tool-router) | Deterministic, fail-open tool routing that cuts first-turn tool-schema tokens, with an optional local-model fallback. |
| [**hermes-loops**](https://github.com/AtlasOmnia/hermes-loops) | Autonomous agent loops: an autoresearch harness plus health and improvement maintenance loops. |
| [**donna-starter**](https://github.com/AtlasOmnia/donna-starter) · [**EMH**](https://github.com/AtlasOmnia/EMH) | Prebuilt Hermes profiles to start from. |

Install any skill in one line, replacing `<skill-name>` with the package directory name:

```bash
hermes skills install https://raw.githubusercontent.com/AtlasOmnia/hermes-custom-pack/main/skills/<skill-name>/SKILL.md
```

Inspect before you install: swap `install` for `inspect`.

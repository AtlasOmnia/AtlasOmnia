*EMH diagnoses software, never people, and provides no medical care — unofficial and fan-inspired.*

Install any skill in one line, replacing `<skill-name>` with the package directory name:

```bash
hermes skills install https://raw.githubusercontent.com/AtlasOmnia/hermes-custom-pack/main/skills/<skill-name>/SKILL.md
```

Inspect before you install — swap `install` for `inspect`.
